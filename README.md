- `softtrade-horeca-landing.html` — главная страница
- `restaurant.html`, `coffee.html`, `bar.html`, `canteen.html`, `cafe.html`, `delivery.html`, `fastfood.html`, `kiosk.html`, `chain.html` — страницы «Описание» для 9 форматов заведений
- `agreement.html` — политика обработки персональных данных
- `CLAUDE.md` — описание проекта и правила работы для Claude Code
- `CHAT_HISTORY.md` — история создания сайта по шагам
- `attachments/` — скриншоты и логотип из чата (не публикуются)

Статический HTML, сборка не нужна. Для просмотра откройте `softtrade-horeca-landing.html` в браузере.
